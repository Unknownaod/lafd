Fire prevention, life safety, and emergency protection requirements

Los Angeles County Fire Code

The Fire Code establishes minimum requirements intended to protect life and property from fire, explosion, hazardous conditions, and other fire-related dangers.

The Los Angeles County Fire Code incorporates the applicable California Fire Code provisions together with amendments and requirements adopted by Los Angeles County.

Official Code Reference The complete 2022 Los Angeles County Fire Code is maintained through the official code reference provided below. Use the full code when researching specific requirements, sections, definitions, or enforcement provisions.

What the Fire Code Covers

Fire Prevention

Requirements intended to prevent fires and reduce conditions that could create a fire or life-safety hazard.

Emergency Access

Requirements involving fire apparatus access, emergency vehicle operations, and access for responding personnel.

Fire Protection

Regulations addressing fire protection systems, alarms, suppression systems, equipment, and related safeguards.

Scope and Administration

Chapter 1 addresses the scope and administration of the Fire Code, including how the code is adopted, administered, interpreted, and enforced.

The broader California Fire Code establishes requirements relating to fire and explosion hazards, hazardous conditions, fire protection systems, and the safety of firefighters and emergency responders.

Reference

2022 Los Angeles County Fire Code

Chapter 1 — Scope and Administration

Code Compliance

Property owners, businesses, contractors, and other responsible parties should review applicable Fire Code requirements before beginning construction, alterations, operations, or activities that may affect fire or life safety.

  • Maintain required fire and life-safety systems.
  • Maintain required emergency access for fire apparatus.
  • Follow applicable requirements for hazardous materials and hazardous operations.
  • Maintain required exits, fire protection equipment, and emergency systems.
  • Comply with applicable inspection, permit, and enforcement requirements.
